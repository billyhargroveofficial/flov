# Loop Development

This directory owns Flov tactical work loops.

- `current-todo/`: the active implementation or research-to-implementation TODO, named `NNN-todo.md`.
- `history/`: completed and verified TODOs, preserving their original number.

Keep durable architecture/platform notes in `docs/`. Keep active research summaries, implementation checklists, goal prompts, verification evidence, and closeout notes here.
